Magpie test site

Each page plays one delivery style. Open the Magpie popup after pressing play.

  1. Progressive MP4 (plain file, <video src>)
  2. Slow progressive MP4 (throttled to about 2 MB/s, for progress and queue checks)
  3. Crawling progressive MP4 (throttled to about 200 KB/s, a download that keeps running)
  4. HLS, MPEG-TS segments
  5. HLS, fMP4, 3 renditions (master playlist, quality picker)
  6. HLS, separate audio rendition (merged into one MP4)
  7. HLS, MPEG-TS with a separate TS audio rendition (merged into one MP4)
  8. HLS, AES-128 encrypted
  9. HLS, byte range single file
  10. Live HLS (records until Stop or the stream ends; cache buster and LL-HLS URL churn)
  11. Live DASH (dynamic MPD, a segment every 4 s, turns static after about 24 s)
  12. DASH ($Number$ template, two qualities, audio merged)
  13. DASH, SegmentTimeline ($Time$ segment names)
  14. DASH, SegmentBase (one file per representation, Range requests)
  15. Gated (segments need the session cookie and a site Referer)
  16. Hidden (manifest URL without extension, wrong MIME; phase 3: MSE capture)
  17. Reddit feed (shreddit markup: a gallery, an image, a GIF, two videos, an ad, a link, a text post; one row per post, every file of it in one click)
