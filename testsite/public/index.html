Magpie test site

Each page plays one delivery style. Open the Magpie popup after pressing play.

  1. Progressive MP4 (plain file, <video src>)
  2. Slow progressive MP4 (throttled to about 2 MB/s, for progress and queue checks)
  3. HLS, MPEG-TS segments
  4. HLS, fMP4, 3 renditions (master playlist, quality picker)
  5. HLS, separate audio rendition (phase 2: merge)
  6. HLS, AES-128 encrypted
  7. HLS, byte range single file
  8. DASH (detected, phase 2: download)
  9. Gated (segments need the session cookie and a site Referer)
  10. Hidden (manifest URL without extension, wrong MIME; phase 3: MSE capture)
